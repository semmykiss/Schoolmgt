     1→// ============================================================================
     2→//  SchoolDesk — Prisma schema
     3→//  ----------------------------------------------------------------------------
     4→//  Conventions
     5→//  - Multi-tenant: every tenant table carries `schoolId`. All API queries are
     6→//    scoped by the authenticated user's schoolId (enforced in lib/api handlers).
     7→//  - Money: stored as Int kobo (₦1.00 = 100). Currency configurable per school
     8→//    (default NGN).
     9→//  - Dates: pure calendar dates are ISO strings "YYYY-MM-DD" (SQLite-friendly,
    10→//    timezone-safe). Timestamps use DateTime.
    11→//  - Enums: SQLite has no native enums → string columns with documented allowed
    12→//    values. When porting to PostgreSQL, swap `provider` and convert to enums.
    13→//  - Soft references (createdById, recordedById, decidedById...) are plain
    14→//    scalar ids (no FK graph) to keep the relation map lean; core domain
    15→//    relations are declared for typed `include` queries.
    16→//  ============================================================================
    17→
    18→generator client {
    19→  provider = "prisma-client-js"
    20→}
